# Grid graph (10×10) adjacency

```python
def build_grid_adjacency(h=10, w=10):
    N = h*w
    A = np.zeros((N, N), dtype=np.float32)
```

* Create an `N×N` adjacency matrix for a 10×10 grid (N=100).

```python
    def idx(r, c): return r*w + c
    for r in range(h):
        for c in range(w):
            i = idx(r, c)
            if r > 0:     A[i, idx(r-1, c)] = 1
            if r < h-1:   A[i, idx(r+1, c)] = 1
            if c > 0:     A[i, idx(r, c-1)] = 1
            if c < w-1:   A[i, idx(r, c+1)] = 1
```

* 4-neighborhood connectivity (up/down/left/right).

```python
    A += np.eye(N, dtype=np.float32)
```

* Add self-loops.

```python
    D = np.sum(A, axis=1)
    D_inv_sqrt = np.diag(1.0 / np.sqrt(D + 1e-8))
    A_norm = D_inv_sqrt @ A @ D_inv_sqrt
    return torch.from_numpy(A_norm)
```

* Symmetric normalization $\hat{A} = D^{-1/2} A D^{-1/2}$ (standard GCN trick).
* Return as torch tensor.

# Simple Graph Convolution

```python
class GraphConv(nn.Module):
    def __init__(self, in_dim, out_dim, A_norm):
        super().__init__()
        self.A = A_norm
        self.lin = nn.Linear(in_dim, out_dim)
```

* Graph conv layer: multiply by normalized adjacency, then a linear.

```python
    def forward(self, x):
        # x: (B, N, F)
        Ax = torch.einsum("ij,bjf->bif", self.A, x)  # (B, N, F)
        return F.relu(self.lin(Ax))
```

* `einsum` applies $\hat{A}x$ per batch.
* Linear projects features from `in_dim`→`out_dim`; ReLU nonlinearity.

# GridGraphEncoder (2 GCN layers + pooling)

```python
class GridGraphEncoder(nn.Module):
    def __init__(self, node_feat_dim=1, hidden_dims=(32, 64), A_norm=None):
        super().__init__()
        self.A = A_norm
        self.gc1 = GraphConv(node_feat_dim, hidden_dims[0], self.A)
        self.gc2 = GraphConv(hidden_dims[0], hidden_dims[1], self.A)
        self.readout = nn.Linear(hidden_dims[1], DMODEL)
```

* Two GCN layers to embed each node; then a linear “readout” to `DMODEL`.

```python
    def forward(self, geom_bits):
        B = geom_bits.size(0)
        x = geom_bits.view(B, 100, 1)  # (B, N, 1) node features=bit
        h = self.gc1(x)                # (B, N, 32)
        h = self.gc2(h)                # (B, N, 64)
        g = h.mean(dim=1)              # global mean pool → (B, 64)
        g = self.readout(g)            # (B, DMODEL)
        return g
```

* Reshape flat 100-vector into per-node features.
* GCN→GCN→global mean pooling→linear → global geometry embedding `(B, DMODEL)`.

```python
        self.w_imag = nn.Parameter(torch.randn(d_model, self.top_k) * 0.02)
```

# Positional encoding

```python
class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=2048):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        pos = torch.arange(0, max_len, dtype=torch.float32).unsqueeze(1)
        div = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(pos * div)
        pe[:, 1::2] = torch.cos(pos * div)
        self.register_buffer('pe', pe.unsqueeze(0))
```

* Precompute sinusoidal table $(1, \text{max\_len}, d)$ and store as non-trainable buffer.

```python
    def forward(self, x):
        L = x.size(1)
        return x + self.pe[:, :L, :]
```

* Add PE to input tokens.

## Quick mental model of the pipeline

1. **Input (B, 100)** binary geometry → reshape to (B, 100, 1) nodes on a 10×10 grid.
2. **GCN ×2** with normalized adjacency → **global mean pool** → **(B, DMODEL)** embedding.
3. **Linear** expands embedding to **(B, 61, DMODEL)** “tokens.”
4. **Spectral blocks** (learned low-frequency mixing) + **Transformer encoder** (self-attention across frequency).
5. **Head** projects each of 61 tokens to **2 channels** → real & imag of $S_{11}(f)$.
6. **Loss**: MSE on $[ \Re, \Im ]$ across all 61 points.
